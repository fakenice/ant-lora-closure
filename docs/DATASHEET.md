# Datasheet：本仓库使用的两份公开语料

生成时间：2026-10-14 · 生成脚本：`scripts/01_fetch_data.py`（取数登记）、`scripts/02_clean_dedup.py`（清洗与评测集构造）、`scripts/03_make_ratios.py`（配比）
所有字节数、sha256、条数均为脚本实测写入 `data/raw_manifest.json` 与 `data/stats/quality_report.json` 的值，不是估计。

## 1. 用途

只回答一个问题：**在后训练数据里，"多轮医疗对话"与"执业医师考试题"两种语料按不同比例混合，会不会让同一个 LoRA 在同一个确定性评测集上产生可测出的差别。** 因此语料范围被刻意压到很小（见 §3、§8）。

## 3. 抽样偏差（必须先读这一条）

对话语料是**按文件顺序的前缀样本，约占全量 4.7%**，不是随机抽样。原始仓库没有可用的随机访问端点（分页 GET 会返回连续字节段，无法做均匀抽样），所以我选择如实登记偏差而不是假装全量。后果：

- 本文任何"配比结论"只适用于"该文件的前缀子集"，不能外推到 `shibing624/medical` 全集；
- 前缀样本内部若存在排序结构（例如按科室或按采集批次排序），会直接进入训练分布。已观察到开头段落来自问答站风格的长答案，但没有对排序结构做过检验——**这一条不能结论**。

## 4. 清洗漏斗（实测，非计划）

对话（`train_zh_0.json` 前缀）：

| 阶段 | 条数 | 相对上一步 |
|---|---|---|
| raw_records | 91,306 | — |
| drop_response_length（`output` 长度不在 20–900 字符） | −29,089 | −31.9% |
| drop_low_zh_ratio（中文字符占比 < 0.5） | −1,344 | −2.2% |

## 5. 评测集构造与防泄漏

从 `test.json` 的 5,839 条有效题中，用固定种子 `20261014` 抽 **100 条**作为评测集（`data/clean/mcq_eval_100.jsonl`）。题面渲染成统一 prompt：

```
以下是一道中国执业医师资格考试单项选择题，请只回答正确选项的字母。
{Question}
A. {value}
B. {value}
...
```

登记在案的分布（这些数字决定了"能不能说涨分"）：

- 正确选项字母分布：A 21 / B 19 / C 15 / D 26 / E 19 → 单靠猜 D 也只有 26%，随机基线 20%（100 条、五选项为主）。
- 选项数：96 条为 5 选项，4 条为 4 选项。
- 题干渲染后 token 长度：min 79 / median 109 / p90 168 / max 252，全部小于评测截断上限 900 → **没有一题因截断而丢选项**。
- **泄漏检查**：对训练池按规范化题面 sha256 去重，从 46,426 条 train 有效题里剔除了与评测集题面相同的 **5** 条，训练池剩 46,421 条。这是精确哈希级去重，不能排除近重复（未对 train/test 做 LSH 交叉判重，属于已知缺口）。

## 6. 配比配置

每组固定 1,200 条、恰好 1 epoch（150 优化步 × 梯度累积 8）：

| 配置 | 对话 | 考题 |
|---|---|---|
| `r100_0` | 1,200 | 0 |
| `r70_30` | 840 | 360 |
| `r30_70` | 360 | 840 |
| `r0_100` | 0 | 1,200 |

抽样用 `random.Random(f"20261014-{name}")`，即同一组内可复现、不同组之间独立。对话侧 assistant 取 `output`，考题侧 assistant **只取正确选项字母**（不含解析），因此训练目标与评测口径（只答字母）严格一致——这一点是刻意的，也是 §8 里一条局限的来源。

## 7. 许可与再分发

两份数据都来自公开 HF 仓库；`shibing624/medical` 与 `fzkuji/CMExam` 的仓库页声明的许可见 `out/model_download.json` 之外的上游页面，本仓库**没有**再分发原始语料：`data/raw/`（113 MB）与全量清洗文件 `data/clean/dialog_zh.jsonl`、`data/clean/mcq_train_pool.jsonl`（108 MB）均在 `.gitignore` 内， clone 后需按 §3 重新取数与清洗。随仓库发布的只有实验实际消费的派生文件——四份配比训练集（各 1,200 行）与评测集（100 行），其字节数与 sha256 见 `data/CHECKSUMS.txt`，`.gitattributes` 对这些文件设了 `-text` 以禁止换行改写。上游授权未做确认，也未对内容做医学正确性审核（§8 第 2 条）。基座模型 `Qwen/Qwen2.5-1.5B-Instruct` 权重按落盘 sha256 登记（3,087,467,144 B），不入库。

## 8. 已知局限（不做结论的清单）

1. 对话语料是 4.7% 前缀样本，代表性未证（§3）。
2. 未做任何人工内容质量或医学正确性审核；对话答案风格像问答站回复，含未经核实的诊疗表述，**不可用于临床**。
3. 评测只有一种题型（执医单选），只测"格式服从 + 知识存取"，不测安全性、拒答行为、多轮一致性。
4. 训练目标与评测目标同构（都只答字母），因此考题比例高者"涨分"部分来自任务格式对齐，不能读成"医学能力提升"。
5. n=100 的准确率 Wilson 95% 区间半宽约 10 个百分点；两组配比之间小于该量级的差别不可区分。
6. 单 seed、单模型（1.5B）、单 epoch，不能区分"配比效应"与"抽样噪声"。
7. train/test 只做精确哈希去重，未做近重复交叉检查（§5）。
8. CMExam 题目为考试题，含大量中成药/方剂考点，与真实临床问诊分布不同。
