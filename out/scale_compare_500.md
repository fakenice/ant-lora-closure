- **1.5B**（`Qwen2.5-1.5B-Instruct`，TAG_PREFIX=`(空)`）：base 329/500 = 65.8%，四档均值 65.1%，四档对 base 的平均 Δ -0.7 pt [-3.5, +1.9]

## 5. 判读

- **1.5B**：四档里显著高于 base 的 0 档（无），显著低于 base 的 1 档（r100_0）；6 对两两比较里 3 对 CI 排除 0；最好档−最差档 9.7 pt。
- **0.5B**：四档里显著高于 base 的 0 档（无），显著低于 base 的 0 档（无）；6 对两两比较里 0 对 CI 排除 0；最好档−最差档 2.6 pt。
- 回答原问题：「配比无稳定提升」**在 0.5B 上同样成立**——四档对 base 的区间全部跨 0，6 对两两比较也全部跨 0。档间最大差是 r100_0 − r0_100 = +2.6 pt，CI [-0.9, +6.1]——含 0（同幅差还有 1 对）。
- 1.5B 上唯一被测出来的档间差异全部涉及 `r100_0`（纯对话档），且它是显著更差：-7.3 pt，CI [-10.6, -4.1]。这个差几乎全来自判分口径：该档 3 seed 共 158 题不可解析（base 只有 1 题），只统计可解析题时 Δ 收到 -0.6 pt。
- 同一个档在 0.5B 上不可解析只有 9 题，Δ 为 +2.9 pt [-0.5, +6.5]，即「纯对话档吃亏」不随规模复现。机制写在 §3 的截断列里：1.5B 的 158 题不可解析有 93 题是用满 max_new_tokens=12 被截断的，0.5B 只贡献了 2 题这种截断——它绑在 1.5B 的长答语风格与生成预算上，不是配比本身的性质。
- 两个规模的四档平均效应甚至不同向：1.5B -0.7 pt [-3.5, +1.9]，0.5B +2.0 pt [-1.4, +5.6]，两者都跨 0，所以「这套 1,200 行 × 1 epoch 的 LoRA 本身有没有用」在两个规模上都判不出。
- 格式效应则随规模复现（结论 3 不受影响）：混入考题数据的三档在两个基座上都塌成单字母（answer-marker 占比 1.5B 0% / 0.5B 0%、平均 2.0 token），纯对话档保留长答语（0.5B 3.9 token / 1.5B 7.2 token）——0.5B 的纯对话档虽然还写「答案：」，但 3.9 token 就写完，没撞上限。
- 这次复核能排除什么：档 vs base 的区间半宽 3.1–4.4 pt，档间配对区间的半宽 2.6–3.6 pt，所以它排除的是「某档配比带来 ≥5 pt 的稳定提升」，排除不了 2–3 pt 量级的效应——0.5B 表里 r100_0、r70_30 并列 44.5%、r0_100 垫底 41.9%，这些点差都落在噪声内。
- 不能从这里外推的东西：只换了两个规模点、一个题源（CMExam 500 题）、一个训练预算（1,200 行 × 150 步）；「规模」在这里只改了参数量，没有分离预训练语料与数据量，而两档 base 的准确率差 24.2 pt（65.8% vs 41.6%）本身就说明可动空间不同。
